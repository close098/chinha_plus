친하 공식 사이트 · 1.3.0

HTML 사이트와 Node.js 서버를 분리한 버전입니다. 로그인·회원 역할·공지·채팅 데이터는 서버에 저장됩니다. 총괄 관리자 로그인은 일반 홈페이지와 분리되어 있습니다.

1. 내 PC에서 실행

  1. 이 ZIP을 새 폴더에 압축 해제합니다.
  2. server 폴더를 열고 탐색기 주소창에 powershell을 입력한 뒤 Enter를 누릅니다.
  3. node server.js를 실행합니다.

Node.js 18 이상이 필요합니다. Docker, PostgreSQL, npm install은 필요하지 않습니다. 터미널에 나오는 사이트 주소를 열어야 로그인과 DB가 작동합니다.

2. 총괄 관리자 전용 로그인

사이트의 하단에 있는 총괄 로그인 링크를 누르거나 주소 끝에 /owner-login을 붙여 접속합니다. 예: http://127.0.0.1:3100/owner-login. 로그인에 성공해야 관리자 대시보드로 이동합니다. 홈페이지 상단에는 총괄 패널 버튼이 표시되지 않습니다.

처음 로컬 실행하면 비밀번호가 터미널과 server/data/admin-initial-password.txt에 생성됩니다. 공개 호스팅에서는 Render 환경 변수 CHINHA_ADMIN_PASSWORD로 처음 비밀번호를 지정하세요. 로그인 후 관리자 보안 메뉴에서 비밀번호를 변경하는 것을 권장합니다.

3. 역할별 패널

  • 시청자: 일반 사이트 기능만 보입니다.
  • 실친: 본인 영상 등록·삭제 및 스태프 채팅
  • 썸네일러: 썸네일 제작 및 PNG 다운로드
  • 채팅 매니저: 커뮤니티·스태프 채팅 관리
  • 교사: 공지 작성, 본인 공지 삭제, 커뮤니티 채팅 관리
  • 총괄: 별도 로그인 후 전체 관리자 기능과 회원 역할 지정

일반 회원은 총괄 역할을 스스로 부여할 수 없습니다. 서버 API에서도 요청한 역할과 로그인 세션을 확인합니다.

4. 공개 인터넷 호스팅

DEPLOY-PUBLIC-HOSTING-KO.md 안내를 따라 GitHub 저장소와 Render를 직접 연결하면 인터넷 접속용 HTTPS 주소를 발급받을 수 있습니다. render.yaml은 Render 배포 설정이며, 이 ZIP만으로 웹사이트가 자동 공개되는 것은 아닙니다.

비용과 권한 안내: 현재 설정은 파일 DB와 업로드를 유지하기 위해 Render 영속 디스크를 사용하도록 되어 있으며 유료 플랜/스토리지 비용이 발생할 수 있습니다. 계정과 결제 설정은 보호자와 함께 확인하세요. ChatGPT는 호스팅 계정에 대신 로그인하거나 배포 버튼을 누를 수 없습니다.

5. 개인정보·DB

실제 회원 DB는 ZIP에 포함하지 않았습니다. 첫 실행 때 서버가 빈 DB를 생성합니다. 개인 데이터, 이메일, 비밀번호 해시가 포함될 수 있는 server/data/db.json, 백업, .env는 공개 GitHub 저장소에 올리지 마세요. 기존 데이터를 옮길 때는 별도 백업 후 비공개 마이그레이션을 해야 합니다.

6. TV·휴대폰

로컬 서버 실행 시 터미널에 나오는 같은 Wi-Fi의 접속 주소를 TV나 휴대폰에서 열 수 있습니다. 다른 장소에서 접속하려면 공개 호스팅 배포가 필요합니다.
